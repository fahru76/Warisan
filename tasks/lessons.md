# Lessons

- Treat GitHub as the only canonical workspace; use GitHub API, Actions, or Codespaces instead of a local clone.
- Never place secrets in repository files, commits, logs, or chat.
- Supabase Preview integration skips frontend-only pull requests when Supabase changes-only mode is enabled; that is expected behavior, not a failed integration.
- Keep browser privacy preferences separate from PDPA registration/booking consent and optional marketing opt-in.
